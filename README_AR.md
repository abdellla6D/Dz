# StoryMaster AI Ultimate 4.1

## ما الذي يقدمه؟
- إنشاء قصة أصلية ومشاهد منظمة عبر Gemini على الخادم.
- العربية والفرنسية والإنجليزية.
- معاينة وتصدير فيديو عمودي WebM بنسبة 9:16.
- إضافة صورة من الهاتف لكل مشهد، وتظهر الصورة في الفيديو المُصدّر.
- قراءة تجريبية للنص بصوت المتصفح (لا يتم تضمين الصوت في ملف الفيديو).
- حفظ واسترجاع المسودة محلياً في نفس الهاتف والمتصفح.
- إعداد بداية OAuth لـ TikTok؛ الربط لا يعني أن النشر التلقائي متاح.

## تشغيله
يتطلب Node.js 20 أو أحدث:
1. فك ضغط ZIP.
2. انسخ `.env.example` إلى `.env`.
3. أضف `GEMINI_API_KEY` و `SESSION_SECRET` في بيئة الخادم فقط.
4. شغّل `npm install` ثم `npm start`.
5. افتح عنوان التطبيق في Chrome.

## الاستضافة
ارفع محتويات المجلد إلى خدمة Node.js تدعم تشغيل Express. أضف متغيرات البيئة في لوحة الاستضافة ولا ترفع `.env`.
استخدم HTTPS واسمح بالجلسات الآمنة. مخزن الجلسات الافتراضي في Express تجريبي وغير دائم؛ لا تعتبره إعداد إنتاج آمناً.

## TikTok
OAuth هنا لربط الحساب فقط. لا يوجد نشر مباشر في هذا الإصدار. يتطلب النشر تطبيق مطور معتمد وصلاحيات TikTok المناسبة، وتجهيز ملف الفيديو، وطلب معلومات المنشئ، وإظهار خيارات الخصوصية، وموافقة المستخدم قبل الإرسال. لا تضع Client Secret أو رموز الوصول في المتصفح أو الدردشة.

## حدود مهمة
- الصور لا تُولّد تلقائياً داخل التطبيق؛ يمكن رفع الصور التي تملك حق استخدامها.
- قراءة الصوت عبر المتصفح للمعاينة فقط ولا تُدمج في WebM.
- ملف WebM صامت.
- المسودة المحلية لا تحفظ الصور المرفوعة.
- لا توجد جدولة أو نشر تلقائي.
